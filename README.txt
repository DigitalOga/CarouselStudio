Carousel Studio - upload EVERY file and folder (including the fonts folder) to the SAME place on your hosting (https:// only).
Open the page in Chrome on Android. Install from the pop-up, or from the ... menu > Install app.
iPhone Safari: Share > Add to Home Screen.
Your carousels autosave on the device (menu > My carousels).
To update later: replace the files. You no longer need to bump any version number. Only change cs-v12 to cs-v13 in sw.js if a new file is added to the fonts folder or the CORE list.
